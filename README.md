# کارکر — دفترچه‌ی سرویس هوشمند خودرو

وب‌اپ فارسی (PWA) برای آیفون که تعویض قطعات، کیلومتر، چک‌های دوره‌ای و خرابی‌های ماشین را ثبت می‌کند و سر موقع یادآوری می‌کند. **تمام اطلاعات فقط روی گوشی خودتان** ذخیره می‌شود (IndexedDB) و برنامه بعد از اولین باز شدن **کاملاً آفلاین** کار می‌کند.

مدل‌های فعلی: **رانا (LX/معمولی، موتور TU5)** و **هیوندای آوانته XD ۲.۰ (G4GC)** — دنده‌ای و اتوماتیک.

## امکانات

- **ثبت تعویض‌ها** با کیلومتر، تاریخ شمسی، هزینه، برند و تعمیرگاه؛ چند قطعه با هم در یک مراجعه (مثلاً روغن + فیلتر روغن + فیلتر هوا).
- **دسته‌بندی قطعات** (موتور، فیلترها، تسمه‌ها، ترمز، گیربکس، خنک‌کاری، …) با سابقه‌ی کامل هر قطعه و «عمر واقعی» آن در ماشین شما.
- **پیش‌بینی موعد** هر قطعه از روی کیلومتر و زمان (هر کدام زودتر)، با تخمین میانگین کیلومتر روزانه از سابقه‌ی شما.
- **یادآور کیلومتر**: هر ۲ هفته (و وقتی چیزی نزدیک موعد است هر هفته) یادآوری می‌کند عدد کیلومتر را وارد کنید.
- **چک دوره‌ای** آب رادیاتور، روغن، شیشه‌شور، باد لاستیک و…: ماهی ۲ بار، و در تابستان (تیر تا شهریور، قابل تغییر) ماهی ۴ بار.
- **علائم و خرابی‌ها**: صدا، لرزش، نشتی، چراغ هشدار و…، با شدت، توضیح و پیگیری خودکار تا وقتی برطرف شود.
- **داشبورد** با امتیاز سلامت، موارد عقب‌افتاده/نزدیک و نشان (Badge) روی آیکن.
- **گزارش هزینه‌ها** (ماهانه، بر اساس دسته، هزینه به ازای هر کیلومتر) و **تاریخچه‌ی کامل**.
- **پشتیبان‌گیری** با منوی Share آیفون (Save to Files / iCloud Drive) و بازیابی از فایل؛ یادآور دوره‌ای پشتیبان.
- **بخش توسعه‌دهنده** (۷ بار روی شماره‌ی نسخه در «بیشتر» بزنید): ویرایش دوره‌ی کیلومتری/زمانی، قیمت، توضیح هر قطعه، افزودن قطعه یا مدل جدید، خروجی/ورودی کاتالوگ و تنظیمات پیشرفته‌ی یادآور.
- حالت روشن/تیره، فونت وزیرمتن (داخل برنامه، بدون نیاز به اینترنت).

## یادآوری‌ها روی آیفون

آیفون به وب‌اپ‌ها اجازه‌ی زمان‌بندی اعلان محلی نمی‌دهد؛ پس دو راه وجود دارد:

1. **تقویم آیفون (پیشنهادی، کاملاً آفلاین):** «بیشتر ← اعلان‌ها ← افزودن یادآورها به تقویم». یک فایل `.ics` با هشدار ساخته می‌شود؛ بازش کنید و Add All بزنید. بعد از ثبت‌های مهم دوباره خروجی بگیرید.
2. **اعلان پوش واقعی (اختیاری):** نیاز به یک سرور کوچک رایگان روی Cloudflare دارد (پایین‌تر). فقط متن و زمان یادآورها به سرور می‌رود، نه اطلاعات ماشین.

همچنین هر بار برنامه را باز کنید موارد لازم روی صفحه‌ی اصلی نمایش داده می‌شود.

## انتشار روی GitHub Pages

1. این شاخه را در `main` ادغام کنید.
2. در GitHub: **Settings ← Pages ← Source: GitHub Actions**.
3. هر push روی `main` تست‌ها را اجرا، برنامه را build و منتشر می‌کند: `https://<username>.github.io/CarCare/`
4. آدرس را در **Safari** آیفون باز کنید ← دکمه‌ی Share ← **Add to Home Screen**. از این به بعد از آیکن باز کنید؛ بدون اینترنت هم کار می‌کند.

> اطلاعات داخل خود برنامه‌ی نصب‌شده است. اگر آیکن را پاک کنید اطلاعات هم پاک می‌شود — قبلش پشتیبان بگیرید.

## اعلان پوش (اختیاری)

نیازمند iOS ۱۶.۴+ و برنامه‌ی نصب‌شده روی Home Screen. یک بار:

```bash
npm install
npx wrangler login
npx wrangler kv namespace create PUSH_KV     # id را در wrangler.toml بگذارید
npm run vapid                                 # کلیدها را چاپ می‌کند (جایی ذخیره نمی‌شود)
npx wrangler secret put VAPID_PUBLIC_KEY
npx wrangler secret put VAPID_PRIVATE_JWK
npx wrangler secret put VAPID_SUBJECT         # مثلاً mailto:you@example.com
npx wrangler deploy
```

بعد در برنامه: «بیشتر ← اعلان‌ها» آدرس Worker (مثل `https://carcare-push.<name>.workers.dev`) را وارد و «فعال‌سازی» را بزنید. پیشنهاد: در `wrangler.toml` مقدار `ALLOWED_ORIGIN` را برابر آدرس GitHub Pages خودتان بگذارید.

**هیچ کلید یا رمزی در مخزن ذخیره نمی‌شود**؛ کلیدهای VAPID فقط به‌صورت Secret در Cloudflare نگه‌داری می‌شوند.

## داده‌های فنی (دوره‌ها و قیمت‌ها)

دوره‌ها برای **شرایط سخت رانندگی در ایران** (ترافیک شهری، گرد و خاک، گرما، کیفیت سوخت) و محافظه‌کارانه انتخاب شده‌اند؛ برگرفته از برنامه‌ی سرویس سازنده‌ها، راهنمای قطعه‌سازها و عرف تعمیرکاران. چند نمونه:

| قطعه | رانا TU5 | آوانته XD ۲.۰ |
|---|---|---|
| روغن موتور + فیلتر | ۵,۰۰۰ کیلومتر / ۶ ماه | ۷,۵۰۰ کیلومتر / ۶ ماه |
| فیلتر هوا / کابین | ۱۰,۰۰۰ / ۱۲ ماه | ۱۵,۰۰۰ / ۱۲ ماه |
| شمع | ۲۰,۰۰۰ | ۳۰,۰۰۰ |
| کیت تسمه تایم + واتر پمپ | ۶۰,۰۰۰ / ۴ سال | ۷۰,۰۰۰ / ۴ سال (سازنده: ۹۶,۰۰۰) |
| روغن گیربکس | ۴۰,۰۰۰ (دستی) | ATF هر ۴۰,۰۰۰ (اتوماتیک) |
| لنت جلو | ~۲۵,۰۰۰ | ~۳۰,۰۰۰ |
| روغن ترمز / ضدیخ | ۲ سال | ۲ سال |
| باتری | ~۳ سال | ~۳ سال |

**قیمت‌ها تخمین تقریبی قطعه + اجرت در مهر ۱۴۰۵ هستند** و به‌سرعت تغییر می‌کنند؛ از بخش توسعه‌دهنده به‌روزشان کنید. همیشه دفترچه‌ی خودرو و نظر تعمیرکار مقدم است.

## توسعه

```bash
npm install
npm run dev        # http://localhost:5173/CarCare/
npm test           # تست‌های منطق موعدها، زمان‌بندی و رمزنگاری Web Push (بردار تست RFC 8291)
npm run build
```

ساختار:

- `src/data/catalog.ts` — کاتالوگ پیش‌فرض قطعات، دسته‌ها و چک‌لیست
- `src/lib/maintenance.ts` — محاسبه‌ی وضعیت و موعد قطعات
- `src/lib/schedule.ts` — ساخت یادآورها (چک‌ها، کیلومتر، قطعات، علائم، پشتیبان)
- `src/lib/ics.ts` — خروجی تقویم
- `src/sw.ts` — Service Worker (آفلاین + اعلان)
- `worker/` — سرور اختیاری اعلان پوش برای Cloudflare Workers
